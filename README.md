# cstore-cloudflare-demo

Static, click-through snapshot of the CStore demo shop, built to run on Cloudflare
(Workers Static Assets) so a page can be served through Cloudflare's CDN — e.g. for
bot-detection demos. There is no backend: nothing is added to a cart or submitted.

## Flow

`/` → `/shop` (4 products) → `/product/<slug>` → `/cart` → `/checkout` → `/checkout/confirmation/ORD-1794240459025`

- "Add to cart" on any page navigates to `/cart`. The cart always holds
  *Converse x Keith Haring Chuck 70* (the same product appears on checkout and confirmation).
- "Place order" navigates to the confirmation page. Form values are placeholders.
- `/shop` is a single static listing of the 4 products. All category / sale / "Shop Now"
  links go to it; the filter sidebar and sort are cosmetic. Other links (login,
  wishlist, …) are inert (`#`).
- The ContentSquare tag `47fe0308b584a` is hardcoded in every page's `<head>`. The
  confirmation page fires its (frozen) e-commerce transaction on load.

## Deploy

Cloudflare Git integration: connect this repo; the default deploy command
`npx wrangler deploy` picks up `wrangler.jsonc` and uploads `public/`.
Add the resulting `*.workers.dev` hostname to the CSQ project's allowed domains.

Local preview: `npx wrangler dev`

## Provenance

The pages in `public/` are rendered HTML from the ecommerce-main Express/EJS app
(captured against a throwaway copy of `shop.db`), with asset paths localized,
server-only/demo-tool UI removed, and links rewritten. They are not generated by
a build step in this repo — edit the HTML directly or re-capture from the app.
